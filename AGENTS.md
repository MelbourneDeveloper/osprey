# Repository instructions

Read and follow [CLAUDE.md](CLAUDE.md) before working in this repository. It contains the shared stabilization, testing, specification synchronization, and repository coordination rules.

**Git worktrees are banned. Only ONE active feature branch is permitted across ALL machines, clones, contributors, and agents combined.** Continue work in the existing checkout on the existing active feature branch. Do not create another branch or worktree for this task.
